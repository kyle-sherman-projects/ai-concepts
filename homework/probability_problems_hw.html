Joint Probability & Independence
Find values for probabilities a and b in the joint probability table so that binary random variables X and Y are independent.
Given — Joint Probability Table
XYP(X, Y)
truetrue2/5

falsetruea = ?

Core Concept

What Does Independence Mean?

Two random variables X and Y are independent if and only if knowing one tells you nothing about the other. Formally, this requires:

P(X, Y) = P(X) · P(Y)    for ALL combinations of values

This must hold for every single cell in the table — not just one. Independence is a global property of the joint distribution.

Key intuition: If X and Y are independent, the joint table is completely determined by the marginals. Every cell is just the product of its row marginal and its column marginal.
Solution — Step by Step
Step 1
Compute the marginal probabilities for X

Sum across Y values for each value of X:

P(X=true) = 2/5 + 1/5 = 3/5
P(X=false) = a + b    (unknown for now)

Since all probabilities must sum to 1:

2/5 + 1/5 + a + b = 1
a + b = 2/5  →  P(X=false) = 2/5
Step 2
Find P(Y) using the independence condition

Use the cell where we know the joint probability — (X=true, Y=true):

P(X=true, Y=true) = P(X=true) · P(Y=true)
2/5 = (3/5) · P(Y=true)
P(Y=true) = (2/5) ÷ (3/5) = 2/3
P(Y=false) = 1 - 2/3 = 1/3
Why use this cell? It's the only one where we know the joint value, so it's the only one we can solve directly.
Step 3
Solve for a and b
a = P(X=false) · P(Y=true) = (2/5) · (2/3) = 4/15
b = P(X=false) · P(Y=false) = (2/5) · (1/3) = 2/15
Answer — a4/15 ≈ 0.267
Answer — b2/15 ≈ 0.133

Law of Total Probability
Given the following probabilities about two Boolean random variables A and B, find the conditional probability P(B = true | A = false).
Given
P(A = true) = 1/2
P(B = true | A = true) = 1
P(B = true) = 3/4
Core Concept

Law of Total Probability

When variable A partitions the space into mutually exclusive, exhaustive cases (A=true and A=false), any marginal probability of B can be expressed as a weighted sum of conditionals:

P(B=true) = P(B=true | A=true)·P(A=true) + P(B=true | A=false)·P(A=false)

Think of it as: "the overall probability of B is a weighted average — weighted by how likely each A-scenario is." We already know three of the four terms, so we can solve for the fourth.

Solution — Step by Step
Step 1
Derive P(A = false)
P(A=false) = 1 - P(A=true) = 1 - 1/2 = 1/2
Step 2
Substitute into the total probability formula
3/4 = (1)(1/2) + P(B=true | A=false) · (1/2)
3/4 = 1/2 + P(B=true | A=false) · (1/2)
Step 3
Isolate the unknown
3/4 - 1/2 = P(B=true | A=false) · (1/2)
1/4 = P(B=true | A=false) · (1/2)
P(B=true | A=false) = (1/4) ÷ (1/2) = 1/2
AnswerP(B=true | A=false) = 1/2
Conceptual Interpretation

The Slack Argument

P(B=true|A=true) = 1 means A=true guarantees B=true. A=true happens half the time, contributing exactly 1/2 to the overall P(B=true).

But P(B=true) = 3/4, which is 1/4 more than 1/2. That extra 1/4 must come from the A=false cases. However, A=false only occurs half the time, so within that group the probability of B must be:

(1/4) ÷ (1/2) = 1/2
Common mistake: The answer is not simply 3/4 - 1 = -1/4 (nonsensical), nor just 3/4. Conditioning restricts you to a subset of the probability space, and you must normalize within that subset.

A = false1/2 · 1/2 = 1/41/2 · 1/2 = 1/41/2

P(B=true) = 2/4 + 1/4 = 3/4 ✓ — matches the given marginal.

Part (a)
Compute the joint probability P(+g, +a, +b, +s)

Apply the chain rule factored according to the network structure. Since G and B are independent root nodes:

P(+g,+a,+b,+s) = P(+g) · P(+a|+g) · P(+b) · P(+s|+a,+b)
               = 0.1 × 1.0 × 0.4 × 1.0
               = 0.04
Answer (a)0.04
Part (b)
What is the probability that a patient has disease A?

Marginalize over G using the law of total probability:

P(+a) = P(+a|+g)·P(+g) + P(+a|−g)·P(−g)
= (1.0)(0.1) + (0.1)(0.9)
= 0.1 + 0.09
= 0.19
Interpretation: Even though G=+g guarantees disease A, the gene is rare (10%). The −g population (90%) still contributes a 10% chance of disease A, giving 9% more. Total: 19%.
Answer (b)P(+a) = 0.19
Part (c)
What is the probability that a patient has disease A given they have disease B?

First, check the network structure. Is there any active path between A and B when S is not observed?

Path: A ← G  ···  B
Only connecting path goes through S (a collider: A → S ← B)
S is NOT observed → collider is BLOCKED → A ⊥ B

Because A and B are d-separated (marginally independent), B provides zero information about A:

P(+a | +b) = P(+a) = 0.19
Why 0.19 and not zero? Marginal independence means B provides no additional information — not that we have no information at all. Our prior belief of 0.19 comes entirely from the G → A pathway, independent of B.
Answer (c)P(+a | +b) = 0.19
Part (d)
What is the probability that a patient has disease A given they have symptom S and disease B?

Now S is observed — this opens the collider and creates dependence between A and B. This is the explaining away effect. Apply Bayes' theorem:

P(+a | +s,+b) = P(+s|+a,+b)·P(+a)·P(+b) / P(+s,+b)

Numerator:

P(+s|+a,+b)·P(+a)·P(+b) = 1.0 × 0.19 × 0.4 = 0.076

Denominator — marginalize P(+s, +b) over A:

P(+s,+b) = P(+s|+a,+b)·P(+a)·P(+b) + P(+s|−a,+b)·P(−a)·P(+b)
= (1.0)(0.19)(0.4) + (0.8)(0.81)(0.4)
= 0.076 + 0.2592
= 0.3352

We want P(+s, +b) — the probability of having both symptom S and disease B, regardless of A's status. Since we don't know A, we sum over both possibilities:

P(+s,+b) = P(+s,+b,+a) + P(+s,+b,−a)

Each joint term expands using the network's chain rule. Since A and B are marginally independent, P(+a,+b) = P(+a)·P(+b), so:

P(+s,+b,+a) = P(+s|+a,+b) · P(+a) · P(+b) = 1.0 × 0.19 × 0.4 = 0.076
P(+s,+b,−a) = P(+s|−a,+b) · P(−a) · P(+b) = 0.8 × 0.81 × 0.4 = 0.2592
Sanity check: 0.3352 < P(+b) = 0.4 — makes sense, because not all patients with B will also show symptom S. The −a term dominates because 81% of patients don't have disease A.
P(+a | +s,+b) = 0.076 / 0.3352 ≈ 0.227
Explaining away: Observing S raised P(+a) from 0.19 to 0.227. But if we also knew −b, it would jump even higher — because without B, S is harder to explain without A.
Answer (d)P(+a | +s, +b) ≈ 0.227
Part (e)
What is the probability that a patient has gene variation G given they have disease A?

Apply Bayes' theorem to reverse the direction G → A:

P(+g | +a) = P(+a|+g)·P(+g) / P(+a)
= (1.0 × 0.1) / 0.19
= 0.1 / 0.19
≈ 0.526
Interpretation: Our prior belief in G was only 10%. Observing disease A updates it dramatically to ~52.6%. This makes sense — G guarantees A, so A is strong evidence for G. The remaining ~47.4% reflects patients who got disease A despite lacking the gene (the −g, +a pathway).
Answer (e)P(+g | +a) ≈ 0.526
Part (f)
What is the probability that a patient has gene variation G given they have disease B?

Check the network: is there any active path between G and B?

Possible path: G → A → S ← B
S is a collider on this path and is NOT observed → path is BLOCKED
There is no other path between G and B.
Therefore: G ⊥ B
P(+g | +b) = P(+g) = 0.1
Compare with (e): Disease A is a direct descendant of G, so it's informative about G. Disease B has no directed or undirected path to G (when S is unobserved), so it tells us nothing. The prior stands.
Answer (f)P(+g | +b) = 0.1
